# Effortless English

Android app for studying the Effortless English courses by A.J. Hoge: a day-by-day lesson plan,
a player with a karaoke transcript and shadowing mode, vocabulary flashcards with spaced
repetition, study reminders, stats, and Android Auto.

The course material is not part of this repository and is not distributed with the app: the app
reads it from the user's own Google Drive (read-only) or from a folder on the device.
`tools/prepare_content.py` turns a copy of the course into the package the app reads.
